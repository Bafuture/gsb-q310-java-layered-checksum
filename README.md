## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的存储文件很大，出现损坏时既要快速发现，又要能定位到具体的小块而不影响其余数据。请从零实现一个分层校验和与损坏隔离组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持分层校验：块级校验和、段级校验和（覆盖其下若干块）与文件级校验和；2) 支持快速判定：文件级校验通过即可跳过全量校验，失败时才逐层下钻定位；3) 支持损坏隔离：定位到损坏块后只标记该块不可用，其余块仍可正常读取，需有测试证明；4) 支持修复判定：结合副本可用性判断损坏块能否修复，并输出修复计划；5) 支持并发校验：多块并行校验，结果汇总要与串行一致；6) 支持校验和算法可替换，并说明不同算法的速度与碰撞风险取舍；7) 提供统计：校验的块数、段数、定位耗时与被隔离块数；8) 测试覆盖三层校验、逐层下钻、损坏隔离后读取、修复判定、并发校验与统计；`mvn -q verify` 一条命令跑通。
